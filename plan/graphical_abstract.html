Especificaciones Técnicas del Proyecto

La Etapa 1 realiza un entrenamiento incremental condicional sobre Nerfacto (Nerfstudio). El dataset activo inicial $D_t$ se expande secuencialmente con imágenes obtenidas desde la pose de la Next Best View (NBV) cuando el modelo alcanza la convergencia.

Algoritmo de Control:

  • Evaluar PSNR promedio sobre $D_t$ en cada época.
  • Si $\text{PSNR}_{\text{promedio}} > \text{Umbral}$ (ej. 28 dB):
    • Guardar checkpoint: pesos_historico/model_t_{iter}.ckpt
    • Obtener pose NBV externa desde next_nbv.json
    • Actualizar Dataset: $D_{t+1} = D_t \cup \{\text{Imagen}_{\text{NBV}}\}$
    • Reanudar el entrenamiento cargando el checkpoint previo (--load-dir)

Para realizar análisis de pesos robustos a la simetría de permutación de las redes neuronales, el extractor extract_features.py reduce los pesos de las capas de la MLP de Nerfacto a estadísticas invariantes por capa:

Estadísticas = { Mean(μ), Variance(σ²), Sparsity(S), L1 & L2 Norms, Top-5 Singular Values (SVD) }

Al usar estadísticas a nivel de capa, garantizamos que si se permutan los nodos (neuronas) dentro de las capas ocultas de la NeRF, el vector de características resultante para el Meta-Modelo se mantiene constante, simplificando drásticamente el espacio de búsqueda.

El Meta-Modelo es una red MLP secundaria entrenada para predecir la traslación $\hat{\mathbf{t}} \in \mathbb{R}^3$ y la rotación continua 6D $\hat{\mathbf{r}} \in \mathbb{R}^6$ (Zhou et al., CVPR 2019) de la pose de Next Best View (NBV) a partir de la trayectoria de pesos.

Ortogonalización de Gram-Schmidt para SO(3):

x_1 = v_1 / ||v_1||
x_2 = (v_2 - (x_1 • v_2) x_1) / ||v_2 - (x_1 • v_2) x_1||
x_3 = x_1 × x_2
R = [x_1, x_2, x_3] ∈ SO(3)

Función de Pérdida Compuesta del Meta-Modelo:

L = MSE(t_hat, t_gt) + λ • arccos( (Trace(R_hat^T • R_gt) - 1) / 2 )
